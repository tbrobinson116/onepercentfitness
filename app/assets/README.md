# App Assets

Place the following image files here:

- `icon.png` - App icon (1024x1024 px recommended)
- `splash.png` - Splash screen image (1242x2436 px recommended)
- `adaptive-icon.png` - Android adaptive icon foreground (1024x1024 px)

For testing, you can create simple placeholder images or use tools like:
- https://placeholdermaker.com/
- https://makeappicon.com/
